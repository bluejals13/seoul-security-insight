# UI Change Workflow

> **적용 시점 (Trigger)**: 대시보드 레이아웃 변경, UI 컴포넌트 추가/수정, 멀티페이지 UI 구조 개편 시  
> **적용 대상 (Scope)**: `components/*.py`, `pages/*.py`, `app.py`

---

## 단계별 UI 변경 절차

### 1단계: 변경 컴포넌트 및 페이지 파악
- 변경하려는 UI 요소가 공통 컴포넌트(`components/`)인지, 특정 페이지 (`pages/`)인지 파악한다.

### 2단계: 관심사 분리 준수하며 UI 수정
- UI 코드 내부에서 데이터 추출, API 수집 또는 전처리를 직접 수행하지 않는다.
- 데이터 및 시각화 객체는 `utils/`, `analysis/`, `visualization/`의 반환값을 전달받아 렌더링한다.

### 3단계: 기존 시각화 요소 하위 호환성 확인
- Plotly 차트 및 Folium 지도 컴포넌트가 깨지지 않고 의도한 위치에 정상 배치되는지 확인한다.

### 4단계: 실행 및 브라우저 검증
- `uv run streamlit run app.py`를 실행한다.
- 가능할 경우 브라우저 렌더링을 통해 화면 레이아웃, 버튼/필터 인터랙션, 반응형 배치를 최종 검증한다.

# Bugfix Workflow

> **적용 시점 (Trigger)**: 앱 구동 오류, 데이터 표시 오류, 시각화 깨짐 등 버그 발생 시 수정 작업 수행  
> **적용 대상 (Scope)**: 모든 버그 수정 작업

---

## 단계별 수정 절차

### 1단계: 원인 분석 및 로그 확인
- 오류 발생 시 예외 로그 및 스택 트레이스(Stack trace)를 전체적으로 확인한다.
- 임의로 추측하지 말고 원인이 발생한 원천 파일과 줄 위치를 명확히 찾는다.

### 2단계: 최소 수정 범위 결정
- 덮어쓰기나 대규모 리팩터링 대신, 버그의 근본 원인을 해결하는 최소한의 수정 범위를 결정한다.
- 기존 아키텍처 계층 원칙을 훼손하지 않는다.

### 3단계: 수정 실행
- 코드를 수정하며 가시적인 예외 감추기(silent try/except)나 하드코딩 패치를 피한다.

### 4단계: 검증 및 회귀 테스트
- 수정된 기능뿐만 아니라 연관된 다른 기능의 정상 동작 여부(회귀 여부)를 검증한다.
- `.agents/rules/testing.md`에 정의된 7단계 검증 순서를 실행하고 테스트 결과를 보고한다.

## 1. 정밀 범죄 수치 및 구성비 공식

- **2024년 5대 범죄 총 발생건수 ($C_{total}$)**: **80,819 건**
  $$C_{total} = C_{violence} + C_{theft} + C_{sexual} + C_{murder} + C_{robbery} = 39,554 + 35,506 + 5,523 + 149 + 87 = 80,819$$

- **범죄 유형별 구성비**:
  - 폭력 ($C_{violence}$): 39,554건 / 80,819건 = **48.9%**
  - 절도 ($C_{theft}$): 35,506건 / 80,819건 = **43.9%**
  - 성범죄 ($C_{sexual}$): 5,523건 / 80,819건 = **6.8%**
  - 살인 ($C_{murder}$): 149건 / 80,819건 = **0.18%**
  - 강도 ($C_{robbery}$): 87건 / 80,819건 = **0.11%**

- **폭력 + 절도 공식합계 ($C_{v+t}$)**:
  $$C_{v+t} = \frac{39,554 + 35,506}{80,819} \times 100 = 92.874\% \rightarrow \mathbf{92.9\%}$$

4.3 주민등록인구 데이터
목적

자치구별 인구 규모의 차이를 보정하기 위해 사용한다.

주요 컬럼
컬럼명	타입	설명
district	string	자치구

활용 지표

인구 1만 명당 범죄 발생률

crime_rate

인구 보정의 필요성

단순 범죄 발생 건수만으로는 자치구 간 치안 수준을 직접 비교하기 어렵다.

예를 들어:

A구 : 범죄 10,000건
B구 : 범죄  5,000건


A구의 범죄 발생 건수가 많더라도 인구가 훨씬 많다면 인구 대비 범죄 발생률은 B구보다 낮을 수 있다.

따라서 본 프로젝트에서는 범죄 발생 건수와 함께 인구 대비 범죄 발생률을 사용한다.

8. 치안 안전 지수
8.1 지수 산출 목적

서로 다른 단위의 데이터를 하나의 기준으로 비교하기 위해 각 지표를 0 ~ 100 범위로 정규화한 후 가중치를 적용한다.

사용 지표
인구 대비 범죄 발생률
CCTV 밀도
가로등 밀도
안전시설 밀도
유동인구 대비 범죄 발생률
8.2 지표 방향

각 지표는 안전에 미치는 방향이 서로 다르다.

지표	값이 클수록	안전 점수
범죄 발생률	위험	낮게 평가
유동인구 대비 범죄율	위험	낮게 평가
CCTV 밀도	인프라 높음	높게 평가
가로등 밀도	인프라 높음	높게 평가
안전시설 밀도	인프라 높음	높게 평가
8.3 Min-Max 정규화

각 지표를 0 ~ 100 범위로 변환한다.

일반 지표

값이 높을수록 안전한 지표:

normalized_score
= (x - min) / (max - min) × 100

위험 지표

값이 낮을수록 안전한 지표:

safety_score
= (1 - (x - min) / (max - min)) × 100

예외 처리

max와 min이 동일한 경우 max - min = 0이 되어 계산할 수 없으므로 별도 처리가 필요하다.

예:

def minmax_safe_score(series, reverse=False):
    min_value = series.min()
    max_value = series.max()

    if max_value == min_value:
        return series * 0 + 100

    score = (series - min_value) / (max_value - min_value) * 100

    if reverse:
        score = 100 - score

    return score

8.4 가중치

초기 가중치는 다음과 같이 설정한다.

지표	가중치
인구 대비 범죄 발생률	40%
CCTV 밀도	25%
가로등 밀도	15%
안전시설 밀도	10%
유동인구 대비 범죄 발생률	10%
합계	100%

가중치는 실제 데이터 분석 결과와 팀 논의를 통해 변경할 수 있다.

8.5 최종 안전 지수 계산

각 지표를 안전 점수로 변환한 후 가중치를 적용한다.

치안 안전 지수
=
범죄 안전 점수 × 0.40
+ CCTV 점수 × 0.25
+ 가로등 점수 × 0.15
+ 안전시설 점수 × 0.10
+ 유동인구 범죄 안전 점수 × 0.10


최종 결과는 0 ~ 100점 범위로 표현한다.

Python 예시
df["safety_index"] = (

16. 데이터 해석 시 주의사항

본 프로젝트에서 산출하는 치안 안전 지수는 공식적인 치안 등급이 아니다.

16.1 범죄 신고 데이터의 한계

범죄 발생 데이터는 실제 범죄 발생뿐만 아니라 다음 요인의 영향을 받을 수 있다.

신고 행태
신고율
경찰의 단속 활동
범죄 집계 방식
데이터 수집 기준

따라서 범죄 데이터의 수치를 실제 범죄 위험도와 완전히 동일하게 해석하지 않는다.

16.2 CCTV의 해석

CCTV가 많은 지역에서 범죄가 적게 발생한다고 해서 CCTV가 직접적으로 범죄를 감소시켰다고 판단할 수 없다.

CCTV 설치 지역은 이미 범죄 발생률이 높거나 유동인구가 많은 지역일 가능성도 있기 때문에 상관관계와 인과관계를 구분해야 한다.

16.3 유동인구의 영향

상업지역 및 관광지역은 주민등록인구보다 실제 생활인구가 많을 수 있다.

따라서 주민등록인구만을 기준으로 범죄 발생률을 계산할 경우 해당 지역의 실제 이용 인구가 충분히 반영되지 않을 수 있다.

16.4 지수 가중치의 한계

안전 지수의 결과는 다음 요소에 따라 달라질 수 있다.

지표 선정
정규화 방법
가중치
데이터 기간
데이터 품질
데이터 집계 방식

따라서 현재의 가중치는 초기 분석 기준이며, 실제 데이터 분석 결과와 팀 논의를 통해 변경할 수 있다.

16.5 지수의 해석 원칙

본 프로젝트의 치안 안전 지수는 정책 결정이나 실제 지역의 위험도를 확정하기 위한 지표가 아니다.

데이터 기반의 자치구 간 상대적 비교 및 탐색을 위한 분석 지표로 활용한다.

# 서울시 생활안전 데이터 인사이트 (Seoul Security Insight) - 정밀 숫자 통일 완료

서울시 25개 자치구의 **5대 범죄 발생 현황(2024), 주민등록 인구(2024), 가로등 보안 인프라(2023)** 데이터를 객관적으로 전수 검증하고, **팩트(Fact), 통계적 결과(Statistical Result), 외부 해석(Interpretation), 한계점/가설(Limitation)**을 엄격히 구분하여 발표자료, 인터랙티브 대시보드, 구조도, 보고서로 재구성한 데이터 분석 프로젝트입니다.

## 2. 정밀 통계 검증 수치 요약 (Statistical Verification)

### A. 범죄 절대건수 vs 인구 1만 명당 범죄율
- **Pearson 상관계수 ($r$)**: **0.186** (선형 상관성 약함)
- **Spearman 순위 상관계수 ($\rho$)**: **0.418** (양의 순위 상관성 관찰)
- **수치 팩트**: 절대건수 1위는 **강남구(6,107건)**인 반면, 인구 1만 명당 범죄율 1위는 **중구(454.65건)**, 2위는 **종로구(383.14건)**로 순위 변동이 존재함.

### B. 가로등 수 vs 범죄 절대건수
- **Pearson 상관계수 ($r$)**: **0.561** (이상치 제외 시 0.540)
- **Spearman 순위 상관계수 ($\rho$)**: **0.523** (이상치 제외 시 0.503)
- **통계 경향 회귀선**: $y = 0.8415 \times x + 2583.40$ (※ 통계적 경향 시각화용이며 인과관계를 의미하지 않음).

### C. 인구 1만 명당 가로등 수 vs 인구 1만 명당 범죄율
- **Pearson 상관계수 ($r$)**: **0.120** (이상치 제외 시 0.104)
- **Spearman 순위 상관계수 ($\rho$)**: **0.287** (이상치 제외 시 0.269)

### D. 이상치 처리 검증 (중랑구 가로등 0건 이슈)
- **[FACT / LIMITATION]**: 중랑구 가로등 수가 **0개**로 보고되었으나, 공공데이터 수집·집계 과정에서의 입력 누락 오차 가능성이 높으며 **현재 데이터만으로는 실제 0개인지 여부를 확인할 수 없음.** 임의로 수치를 변경하지 않고 원본 데이터를 보존함.
